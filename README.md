# Team Indigo website

Next.js and GSAP concept site for Team Indigo, the event management club at Gyan Ganga Institute of Technology and Sciences.

## Run

```bash
npm install
npm run dev
```

`npm run build` creates a static export in `out/`. The site has Home, Events, About, and Contact routes.
